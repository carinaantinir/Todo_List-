

# 

##  Todo List — Seguí al conejo blanco 🐇

        ¿Querés salir del bucle? Empezá por vos.

Inspirada en el universo de Matrix y su invitación a cuestionar los patrones que repetimos, Todo List propone una manera diferente de relacionarnos con nuestras tareas cotidianas.
 
 A veces, salir del bucle no significa hacer grandes cambios, sino animarnos a dar el primer paso: organizarnos, establecer pequeñas metas y descubrir que avanzar también puede ser sencillo.

Esta aplicación fue creada con una mirada especialmente orientada a inspirar a las mujeres, combinando una estética femenina, delicada y minimalista con herramientas prácticas de organización.

Su paleta de colores rosados, sus animaciones y su navegación intuitiva buscan transmitir tranquilidad y entusiasmo, alejándose de la idea de que la productividad debe ser rígida, complicada o abrumadora.

El proyecto nace durante mi formación en desarrollo Frontend ADA, donde cada nuevo conocimiento se convirtió en una oportunidad para experimentar, crear y desarrollar una identidad visual propia.

Porque la disciplina también puede ser amable, la constancia puede construirse de a poco y cada tarea completada puede convertirse en una pequeña conquista.

Seguí al conejo blanco. El primer paso lo das vos.

##  Funcionalidades

- Agregar nuevas tareas.
- Marcar tareas como completadas o pendientes.
- Eliminar tareas.
- Filtrar tareas por estado.
- Guardar tareas mediante localStorage.
- Navegar desde una introducción animada hacia la aplicación.
- Interfaz adaptable a diferentes tamaños de pantalla.
- Diseño responsive: interfaz adaptable a diferentes tamaños de pantalla, como computadoras, tablets y celulares

##  Tecnologías utilizadas

- Tecnologías utilizadas: React, JavaScript, Vite, Tailwind CSS.
- Bibliotecas: Lucide React.
- Herramientas: Git, GitHub y pnpm.


##  Conceptos aplicados
- Diseño y desarrollo de una interfaz con identidad visual propia.
- Componentes reutilizables.
- Props y estados con `useState`.
- Manejo de eventos.
- Renderizado condicional.
- Renderizado de listas.
- Persistencia de datos.
- Organización del proyecto por componentes.
- Control de versiones mediante ramas y Pull Requests.
- Diseño responsive con Tailwind CSS.

## Instalación local

```bash
pnpm install
pnpm dev
```

##  Diseño

El proyecto incorpora una identidad visual propia, con una paleta de colores rosados, elementos binarios, una animación introductoria y una experiencia de navegación narrativa.

## Sobre el proyecto

Desarrollado como proyecto integrador de React, con el objetivo de aplicar los conocimientos adquiridos durante la formación en desarrollo frontend.
